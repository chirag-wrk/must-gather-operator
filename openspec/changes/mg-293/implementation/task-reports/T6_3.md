## Summary

Added pre-Job reconcile validation for custom obfuscation ConfigMaps. When obfuscation is enabled and a custom config ref is set, the controller GETs the ConfigMap in the operator namespace and verifies the `config.yaml` key exists before creating the Job. Validation failures set `ObfuscationConfigInvalid` and block Job creation.
